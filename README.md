# Local Mail MCP

Local Mail MCP is a small personal tool that lets an AI assistant running on the owner's own computer read and write the owner's own Gmail messages.

- It runs only on the owner's computer. There is no hosted service.
- It is used only by its owner, with the owner's own Google accounts.
- It requests two permissions: reading mail (`gmail.readonly`) and creating drafts or sending mail (`gmail.compose`).

See the [privacy policy](PRIVACY.md).
