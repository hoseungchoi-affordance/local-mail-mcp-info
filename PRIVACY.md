# Privacy Policy — Local Mail MCP

Last updated: 2026-11-22

Local Mail MCP is a personal tool used only by its owner with the owner's own Google accounts.

## What data is accessed

With the account owner's consent, the tool accesses Gmail messages (reading and searching) and creates drafts or sends messages on the owner's behalf.

## How data is used

Data is used only to carry out the owner's own requests, such as finding a message or drafting a reply.

## Storage and sharing

- The tool runs only on the owner's computer. It has no server and no database.
- Sign-in tokens are stored only on the owner's computer.
- The tool does not collect, sell, or share data with anyone. Message content the owner asks an AI assistant to read or write is passed to that assistant to fulfil the request, and nowhere else.
- Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access

Access can be removed at any time at https://myaccount.google.com/connections.

## Contact

Open an issue on this repository.

# 개인정보처리방침 — Local Mail MCP

Local Mail MCP는 소유자 본인이 본인의 Google 계정으로만 사용하는 개인용 도구입니다.

- 접근하는 데이터: 계정 주인의 동의하에 Gmail 메일을 읽고 검색하며, 초안을 만들거나 메일을 보냅니다.
- 사용 목적: 소유자 본인의 요청을 수행하는 데에만 사용합니다.
- 저장과 공유: 소유자의 컴퓨터에서만 실행되며 서버나 데이터베이스가 없습니다. 로그인 토큰은 소유자의 컴퓨터에만 저장됩니다. 데이터를 수집·판매·공유하지 않습니다.
- 접근 해제: https://myaccount.google.com/connections 에서 언제든 연결을 끊을 수 있습니다.
- 문의: 이 저장소에 이슈를 남겨 주세요.
